# The ChainBloom public site

`site/` is what GitHub Pages serves at
<https://bitcoinuniverseio.github.io/chainbloom/>.

Two parts live here:

- **The landing page.** `index.html`, `styles.css`, `app.js`, `404.html`, and
  the images in `assets/`. These are written by hand.
- **The documentation.** `docs/`, generated by `npm run build:docs` from
  `content/` and from the built package. It is not committed; the Pages workflow
  builds it before uploading. Its stylesheet and scripts (`assets/docs.css`,
  `assets/docs.js`, `assets/demos.js`, `assets/marker.mjs`) are written by hand
  and are committed.

Preview it exactly as it is published, including the `/chainbloom/` path prefix:

```bash
npm run build && npm run build:docs && npm run serve:docs
```

The site uses semantic HTML, local images, system fonts, visible focus states,
reduced-motion support, and a light or dark theme. It has no analytics, no
cookies, no forms, no account data, and no third-party runtime assets. Every
page works with scripts turned off; scripts add search, saved reading progress,
glossary tooltips, and the interactive figures.

`npm run check:site` guards the landing page copy and assets.
`npm run check:docs` guards the generated documentation: broken links, metadata,
heading order, alt text, sitemap and search coverage, claims this project does
not make, and code samples marked `verify`.
