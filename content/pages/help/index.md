:::lead
Something is not working, a word makes no sense, or you want to know what is real before you sign anything. These four pages answer those questions in plain words, and they say "no" and "not yet" where that is the honest answer.
:::

## Where to go first

If a message on your screen has stopped you, start with [troubleshooting](/docs/help/troubleshooting). It is arranged by what you see, not by which part of the code produced it.

If you are deciding whether to take part at all, start with [what is running today](/docs/help/status). The protocol is written and tested, but the public read index is not switched on, and no released wallet knows what a [[carrier]] is. Knowing that before you spend a fee is worth more than any other page here.

## What is not on these pages

No live numbers. There is no public index to read, so any count of [[world|worlds]], paths, or contributions on this site would be invented. Where a count belongs, these pages link to [what is running today](/docs/help/status) instead.

No wallet walkthroughs. No released wallet recognises ChainBloom outputs, so there is no true sentence of the form "your wallet will show you X". What you get instead is what to check yourself before you sign, in [wallet connection and review](/docs/participate/wallet-and-review).

No reassurance about money. Taking part costs a real Bitcoin miner fee, plus {{CARRIER_VALUE_SATS}} satoshis held in each path output while that path is alive. A confirmed action cannot be undone by anyone, including the people who wrote this. [Fees and confirmation](/docs/participate/fees-and-confirmation) gives the real numbers.

The full list of every code the protocol can emit lives in the [error reference](/docs/reference/errors), with the rule behind each one and the file it lives in.
